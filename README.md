# neural-network-from-scratch
Цель проекта – создание полносвязной нейронной сети с нуля.

---

#### Пока что реализован SGD 
- Пример обучения для распознавания цифр из MNIST можно посмотреть в `main.cpp`.
- Пример загрузки нейросети из файла и проверки точности распознования цифр из MNIST можно в `main_check.cpp`.

После создания нейросети с помощью NetBuilder надо вызвать метод `train_SGD(X, Y, epochs, learningRate, batchSize)` у экземпляра класса Net

`train_SGD` - выполняет обучение нейронной сети с использованием стохастического градиентного спуска (SGD). 
Метод принимает обучающие данные X и Y, количество эпох epochs, скорость обучения learningRate и размер батча batchSize, и выводит прогресс обучения и точность на тренировочной выборке.
